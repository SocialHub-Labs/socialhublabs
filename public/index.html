GOOD TO KNOW

Questions,
answered.

Is SocialHub Studio actually free?

Yes. All current tools on this site are free to use. We don't require a subscription or payment details.

Do I need to register or create an account?

No. The tools run in your browser. Studio saves edits in browser storage; export a JSON backup if you want to move between devices.

Does a shared link create a permanently hosted profile?

No. The share function encodes the profile data into the URL fragment. It creates a useful preview link, not an account-backed hosted profile. For a stable published site under your control, download the standalone HTML file and host it yourself.

Does SocialHub connect to my social media accounts?

No. This MVP helps you create links and assets for your online presence. It does not request social account permissions, schedule posts or access platform APIs.
